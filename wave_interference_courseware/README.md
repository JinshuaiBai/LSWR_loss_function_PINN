# 一维波干涉课件（可双击运行）

## 使用方法（Windows）
1. 打开本文件夹。
2. 直接双击 `双击打开课件.bat`（推荐）或 `index.html`。
3. 课件会在默认浏览器中打开，可离线运行。

## 功能说明
- 一维线上等距点阵实时振动。
- 左侧和右侧可分别设置简谐波参数：振幅、频率、波长、波速、初相。
- 两列波分别向右/向左传播，并实时显示叠加结果（干涉效果）。
- 提供暂停、重置、右波相位加 π（快速演示相消）等按钮。

## 参数建议（课堂演示）
- **演示驻波**：左右波参数一致（A、f、λ相同，初相差为 0）。
- **演示相长干涉**：两波同频同相，观察某些点位移增强。
- **演示相消干涉**：点击“右波相位+π”后观察位移减弱。

## 兼容性
- 推荐浏览器：Edge / Chrome / Firefox 新版本。
- 文件基于 HTML + JavaScript，无需额外安装运行时。
